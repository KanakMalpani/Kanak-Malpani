# Kanak Malpani

Personal site for Kanak Anil Malpani, a second-year electrical engineering student at NIT Tiruchirappalli.

The page is static: `index.html`, `styles.css`, and `site.js`. GitHub Actions publishes those files, the CV, and the favicon to [GitHub Pages](https://kanakmalpani.github.io/Kanak-Malpani/).

## Publish

In the repository settings, open **Pages** and set **Source** to **GitHub Actions**. The workflow `.github/workflows/pages.yml` deploys on every push to `main`.
