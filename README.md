# Kanak Malpani

Personal site for Kanak Anil Malpani, a second-year electrical engineering student at NIT Tiruchirappalli.

The site is static. The home page is the folio. Notes, research papers, project write-ups, a monthly Now page, and About live beside it. GitHub Actions publishes the pages, the CV, and the favicon to [GitHub Pages](https://kanakmalpani.github.io/Kanak-Malpani/).

## Publish

In the repository settings, open **Pages** and set **Source** to **GitHub Actions**. The workflow `.github/workflows/pages.yml` deploys on every push to `main`.
